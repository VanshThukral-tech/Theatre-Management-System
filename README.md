# Theatre-Management-System
The Theatre Management System helps reduce manual work, improves booking accuracy, and provides an organized way to manage theatre operations using Python. It includes 3 modules i.e. billing, booking and movies. 
1.Movie Module: Allows users to view available movies, their timings, genres, and other basic details.
2.Booking Module: Enables customers to select a movie, choose a show timing, select the number of seats, and confirm their ticket booking.
3.Billing Module: Calculates the total ticket cost based on the number of seats and ticket price and generates a final bill for the customer. 

# How the System Works
1.Run the main program.
2.Select Show Movies to view the available movies.
3.Select Book Ticket to choose a movie.
4.View the available seats.
5.Enter the number of tickets required.
6.Enter the desired seat numbers.
7.Available seats are marked as booked.
8.The system generates and displays the ticket bill.
9.Select Show Seats at any time to check seat availability.
10.Select Exit to close the application.
